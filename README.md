# Experience Community

The owner uploads experience videos. Visitors watch, like, rate and comment.

## Start

```bash
nvm use            # Node 22
npm install
cp .env.example .env.local   # fill in keys
npm run dev
```

## Checks

```bash
npm run lint
npm run typecheck
npm run build
```

Project rules are in `CLAUDE.md`. The plan and handoff notes are in `NOTES/`.
