## Set up on the Mac

1. Install Node 22 (`.nvmrc`), git, and sign in to GitHub (`gh auth login`).
2. `git clone https://github.com/syrethestar-sys/no-name.git && cd no-name && npm ci`
3. Unpack the extras in the repo folder: `tar -xzf ~/Downloads/no-name-extras.tar.gz`
4. Create `.env.local` by hand (use `.env.example` as the list; keys from each service's dashboard or the owner's password manager). Remember `PINECONE_INDEX` holds the index **host**.
5. `npm run dev`, then sign in and check the feed, a video page and `/search`.

Not needed: `node_modules/`, `.next/`, `tsconfig.tsbuildinfo`, `next-env.d.ts` (rebuilt).
Lockfile rule still applies: after installing packages run `npx npm@10 install --package-lock-only`, or CI's `npm ci` fails.
